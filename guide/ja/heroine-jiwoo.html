藤田美桜 攻略

開発系インフルエンサーの称号専用の登録者、ブートキャンプ受講生の美桜。質問 #12から質問 #1000のプロポーズまで、ログハウスの新婚とエンディング3つ

最終更新 2026-11-20

藤田美桜（@コミットの妖精） 🧚難易度★★★★★

自分の動画で勉強するブートキャンプの受講生。質問に番号をつけてDMを送ってきて、初就職、初PR、初めての後輩まで、自分と一緒に成長していきます。

結婚可同棲新婚育児
ひとことまとめ
  • 開発系インフルエンサーの称号の周回で登録者1万人（第8週〜）になると登場します。
  • 片想いの段階では好感度が登録者の中でいちばんゆっくり上がりますが、片想いまでは早く来ます。デートをよくするほど早く近づけます。
  • 夢の家はサーバー山脈のログハウス（基準1.2億円）。新婚エンディングまで狙うなら、投資でまとまったお金を必ず作っておきましょう 💰

美桜はvar、let、constの中でどれが一番好きですか？性格診断みたいなものです笑で始まる、質問の多い後輩のような登録者です。告白は質問 #500、プロポーズは質問 #1000。称号ストーリーのルールと登録者共通の落とし穴は穂乃果の攻略にまとめたので一緒に見てください。共通の恋愛ルールはこちら。

好感度の上げ方#

第8週からコメント、DMで来ます。インフルエンサーの称号だと登録者のおしゃべりが別に来るので、メッセージが多いです。

  • いい返信: 親切に教えてあげる1番目の返信。好感度が上がりますが、体力、ストレスを少し使います。
  • 悪い返信: 冷たく流す最後の返信。最初の5通では -10、交際後は -12まで削られます。
  • 投げ銭のメッセージには名前を呼んで応援すればOK。初就職のお祝いのご飯はおごってあげましょう（-1.1万円）。
  • 交際からは初PRの額縁、チャンネルへのゲスト出演のように、彼女の成長を応援するメッセージが来ます。

片想い → 告白 → 交際#

  1. 片想いの誘い（80）初任給もらいました！…一度ご飯おごらせてもらえませんか？ → いいですよ。質問は3つまでね（+5）。気持ちだけいただきますは去っていきます。
  2. 片想いの期間好感度が登録者の中でいちばんゆっくり上がります。デートを休まずこつこつ。
  3. 告白（100）質問 #500です。本当に最後の質問。 → 正解：はい（+5、ストレス -5）。いい後輩でいてくださいは去っていってロック。

結婚の条件#

デートの進み具合60 + 好感度100で質問 #1000。これは正解がひとつだけ。私と結婚してくれる？ → constで答えるよ。うん（+10、ストレス -8）。断ると -15で二度と来ません。（エンディング図鑑の文の進み具合20は間違いで、60が正しいです。）

失敗、別れの条件#

  • 第2週に最初の動画を上げないと、1万人のメッセージも来ないので美桜に会えません。
  • 片想いの誘いを断る = 美桜だけが去る / 告白を断る = 去っていく + ロック / プロポーズを断る = 二度と来ない。
  • デート0回の週 -30、家事0回の週 -30、好感度0なら別れ、離婚のメッセージ（引き止め30%）。
  • 第54週以降の称号メッセージの周回終了の選択肢は避けましょう（穂乃果の攻略の表参照）。

よくある質問#

穂乃果が先に来て美桜とつながりません
片想いの誘いは誰とも付き合っていないときだけ来て、告白は100に先に届いた片想いの相手から来ます。美桜だけを狙うなら、穂乃果、真由には冷たい返信をするか片想いの誘いを断りましょう（片想いの誘いを断ってもロックはなし）。
美桜はなぜ片想いで時間がかかるの？
片想いの段階で好感度がほかの登録者よりゆっくり上がるからです。そのかわり片想い前は穂乃果より早く上がります。
